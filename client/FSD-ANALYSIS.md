# Анализ структуры проекта по Feature-Sliced Design 2.1

## Текущая структура проекта

Проект в целом следует методологии Feature-Sliced Design (FSD), но требует некоторых улучшений для полного соответствия версии 2.1. Текущая структура:

```
client/src/
├── app/           # Инициализация приложения, роутинг, провайдеры
├── entities/      # Бизнес-сущности
├── features/      # Функциональные части приложения
├── pages/         # Страницы приложения
├── processes/     # Бизнес-процессы
├── shared/        # Переиспользуемые модули
└── widgets/       # Композиционные компоненты
```

## Правила импорта

В FSD 2.1 важно соблюдать правила импорта между слоями:

1. Слои могут импортировать только из нижележащих слоев:
   - `app` → `processes` → `pages` → `widgets` → `features` → `entities` → `shared`

2. Запрещены импорты из вышележащих слоев.

3. Запрещены импорты из соседних сегментов одного слоя.
