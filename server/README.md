# API для интернет-магазина

## Аутентификация и пользователи
- `/auth/registration` - Регистрация пользователя (POST)
- `/auth/login` - Вход пользователя (POST)
- `/auth/logout` - Выход пользователя (POST)
- `/auth/refresh` - Обновление токена (GET)
- `/auth/activate/:link` - Активация аккаунта (GET)
- `/users` - Получение списка пользователей (GET, только для админов)

## Продукты
- `/products` - Получение всех продуктов (GET)
- `/products/:id` - Получение продукта по ID (GET)
- `/products/category/:category` - Получение продуктов по категории (GET)
- `/products` - Создание нового продукта (POST, только для админов)
- `/products/:id` - Обновление продукта (PUT, только для админов)
- `/products/:id` - Удаление продукта (DELETE, только для админов)

## Модели данных

### Пользователь (User)
- email - Электронная почта пользователя
- password - Пароль пользователя
- role - Роль пользователя (user, admin)
- isActivated - Статус активации аккаунта
- activationLink - Ссылка для активации аккаунта

### Продукт (Product)
- title - Название продукта
- description - Описание продукта
- price - Цена продукта
- imageUrl - URL изображения продукта
- category - Категория продукта
- inStock - Наличие продукта на складе
- quantity - Количество продукта на складе
- createdAt - Дата создания
- updatedAt - Дата обновления

## Middleware
- authMiddleware - Проверка авторизации пользователя
- checkRoleMiddleware - Проверка роли пользователя
- errorMiddleware - Обработка ошибок

## Сервисы
- authService - Сервис для работы с аутентификацией
- userService - Сервис для работы с пользователями
- productService - Сервис для работы с продуктами
- tokenService - Сервис для работы с токенами
- mailService - Сервис для отправки электронной почты
